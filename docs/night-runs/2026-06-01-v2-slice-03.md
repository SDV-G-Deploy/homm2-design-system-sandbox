# HoMM2 x Solarpunk V2 Slice 03 - Visual Depth And Desktop Discipline

Date: 2026-06-01

## Goal

Improve V2 without adding another screen or expanding the primitive count.

Slice 03 focuses on the two weak points identified after slice 02:

- desktop pages felt like stretched mobile cards;
- the asset layer depended too much on one SVG plus CSS surfaces.

An independent explorer critique agreed with this direction: do not add an eighth primitive; strengthen desktop breakpoint, material surface roles, and framed asset grammar.

## Changes

- Added `assets/v2/solar-badge.svg` as a compact brass route badge.
- Added `assets/v2/water-lens.svg` as a reusable water inspection motif.
- Added `assets/v2/vellum-grain.svg` as a reusable vellum texture.
- Added a civic command rail to `v2/index.html` desktop/mobile flow.
- Added asset strip proof to `v2/reference.html`.
- Added water lens motif to `v2/dossier.html` instrument panel.
- Widened desktop canvas and strengthened desktop hero layout.
- Scoped dark-card route rows so reference rows stay readable instead of grey/muddy.
- Preserved the mobile-first structure and existing V2 primitive count.

## Result

V2 now has more visual depth and a stronger desktop story:

- gateway desktop starts with the asset scene instead of empty air;
- right rail carries real route/status material instead of only buttons;
- reference board shows multiple asset roles, not one hero SVG;
- dossier desktop has a stronger instrument panel;
- route/status rows keep readable tone inside dark cards;
- captures report zero horizontal offenders on desktop, mobile, and narrow.

## Remaining Risk

V2 still needs a replacement decision. Next pass should decide whether to promote V2 into the public default path or keep it as a `/v2/` parallel system while one more real site/page is built from the kit.
