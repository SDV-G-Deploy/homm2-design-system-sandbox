State checks

The route is not finished until the blocked gate is named.

The basin and terrace are stable. The east gate is the only uncertain point, so the map keeps that state visible instead of hiding it in a green route line.

The crew can move tools to the terrace today, but water release waits for one clean silt reading. That is the difference between a pretty path and an operational route.
