## Design Notes

The page is RU-first and production-like. It uses short navigation, a clear offer, method, audience fit, format, and final CTA.

The visual assets are SVG because the first asset-pass roles need crisp UI motifs and scalable system grammar before heavier bitmap hero/detail assets.
