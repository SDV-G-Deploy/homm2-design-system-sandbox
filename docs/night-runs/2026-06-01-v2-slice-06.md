# V2 Slice 06 - Control Board Trial

## Goal

Prove V2 on a second real page shape that is not a landing/product page.

## Page Added

- `v2/control.html`

The page is a dense operational control board with:

- compact V2 navigation
- route filters
- sun-vellum queue rows
- summary metrics
- water-lens inspection panel
- separated command rail

## System Value

This pass tests whether HoMM2 x Solarpunk V2 can support an app-like work surface:

- reading and queue management stay on vellum
- state and inspection stay in dark/lens surfaces
- commands are separate from record rows
- RU/EN labels remain short enough for narrow mobile

## Follow-up Correction

After mobile review, the control board exposed a product-chrome issue:

- proof labels looked like permanent product UI;
- sandbox navigation required horizontal scrolling and clipped routes on mobile.

Correction:

- `v2/control.html` and `v2/trial.html` now use `v2-production-page`;
- proof chips with `data-proof-chrome="true"` are hidden on production-like pages;
- control board mobile navigation is reduced to `Summary`, `Queue`, `Actions`;
- trial mobile navigation is reduced to `Proof`, `Plans`, `Board`.
