Визуальные элементы живут как слоты, а не как случайные картинки.

Эта витрина фиксирует, какие SVG/WebP элементы уже принадлежат V2: где их применять, какой у них fallback, и почему они не заменяют HTML, CSS, состояния или текст.

Смотреть слоты Asset kit
Slot law

Изображение получает место только после роли.

  • Layout CSS owns structure, spacing, responsive behavior
  • Meaning HTML owns copy, labels, commands, metrics
  • Image Asset owns material, object, seal, texture, atmosphere
