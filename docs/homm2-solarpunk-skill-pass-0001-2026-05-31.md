## Skill Role

Use `homm2-solarpunk-design` when a task asks to:

- improve the HoMM2 x Solarpunk direction;
- audit whether a page is just a green/eco skin;
- apply Fantasy Solarpunk to an existing HoMM2 page;
- build a component/reference proof board;
- define material roles, state vocabulary, or reusable CSS for the flavour;
- brief another agent on this visual system.

## Key Gates

- Not a skin: changes must affect material roles, states, components, or page structure.
- HoMM2 preserved: frames, plaques, ledgers, bevels, object UI, threshold hierarchy.
- Solarpunk visible: solar infrastructure, water focus, living state, civic/regenerative nouns.
- Portable grammar: at least one reusable class/pattern or reference-board row improves.
- Applied proof: at least one real page beyond `solarpunk.html` demonstrates the grammar.
- Mobile proof: no horizontal overflow or unreadable command/state labels at mobile widths.
