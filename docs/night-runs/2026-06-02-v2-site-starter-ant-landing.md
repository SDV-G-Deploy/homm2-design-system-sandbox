# V2 Site Starter + ANT Landing V1

## Goal

Turn the mature V2 recipe kit into a copyable site starter and use ANT School as the first stronger production landing example.

## Changes

- Added `starters/v2-site-starter/` as a plain-HTML starter for new V2 sites.
- Updated `v2/ant-school.html` from a production trial toward landing v1:
  - clearer first-screen offer;
  - short production navigation;
  - threshold asset slot using `solar-civic-gate.svg`;
  - four-step builder route;
  - output desk section;
  - focused final CTA.
- Added ANT threshold/proof recipe CSS in `css/v2.recipes.css` and responsive behavior in `css/v2.responsive.css`.
- Added the starter page to `tools/regression-smoke.js`.
- Updated README, starter kit, and acceptance notes.

## Rule

Use `starters/v2-site-starter/` for the next new landing before extracting an npm/component library.

The starter should prove repeatable page assembly while V2 component needs continue to stabilize across real pages.
