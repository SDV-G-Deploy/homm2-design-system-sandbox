# HoMM2 x Solarpunk V2 Slice 02 - Reference And Applied Proof

Date: 2026-06-01

## Goal

Check whether V2 is more than one good gateway screen.

Slice 02 extracts the same small kit into a primitive board and proves it on a second applied screen.

## Added Pages

- `v2/reference.html` - compact seven-primitive board
- `v2/dossier.html` - second applied dossier screen

## Reused Primitives

1. Compact mobile shell and navigation
2. Reading-safe vellum panel
3. Brass command plate
4. Route/status row
5. Water inspection module
6. Material badge/chip
7. Asset-backed framed motif

## Design Decisions

- Keep the reference board small: seven primitives only.
- Keep applied proof close to a real content screen: dossier heading, readable copy, statuses, and one command.
- Preserve RU/EN content-budget proof in visible UI.
- In applied headers, badges wrap instead of relying on horizontal scroll.
- Extend smoke coverage to `v2/reference.html` and `v2/dossier.html`.
