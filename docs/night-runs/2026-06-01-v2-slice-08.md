# V2 Slice 08 - ANT School Production Trial

## Goal

Apply the V2 starter kit to a real topic outside the design-system sandbox vocabulary.

Topic: **ANT School / ANT Space** - a school and builder commune for AI non-technical builders.

## Page Added

- `v2/ant-school.html`

## Direction

The page presents ANT School as a builder commune and practical learning route:

- bring an idea;
- turn it into a product map;
- create an agent-ready build brief;
- produce a visible artifact or next step.

## Starter Kit Use

- Uses `body.v2-production-page`.
- Uses page-local production nav: `Program`, `Guild`, `Join`.
- Does not show proof chips or sandbox routes.
- Uses V2 surfaces:
  - dark hero threshold;
  - vellum learning route;
  - dark readiness signal;
  - primitive role cards;
  - final join ledger.
- Keeps commands separate from record/state rows.

## Why This Matters

This proves V2 can carry a real product/service topic without leaning on HoMM2/Solarpunk sandbox labels such as Gate, Ref, Trial, or proof chips.
