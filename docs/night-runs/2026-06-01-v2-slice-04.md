# HoMM2 x Solarpunk V2 Slice 04 - Real Page Trial

Date: 2026-06-01

## Goal

Test whether V2 can produce a real page, not only a gateway, reference board, or design-system proof.

The trial page is a compact fantasy-tool landing page built from the existing V2 primitives without adding an eighth primitive.

## Added Page

- `v2/trial.html` - Sunwell Dispatch real page trial

## What It Tests

- Offer headline and product-positioning copy
- Primary and secondary CTA
- RU/EN content-budget badges
- Feature proof cards
- Launch-route rows
- Asset-backed hero scene
- Mobile-first composition
- Desktop composition using the same V2 shell

## Design Decision

The first trial should stay intentionally small. It reuses existing primitives instead of creating new decorative blocks:

- `v2-topbar`
- `v2-hero`
- `v2-artframe`
- `v2-route-card`
- `v2-command`
- `v2-civic-rail`
- `v2-panel`
- `v2-primitive-card`
- `v2-ledger`
- `v2-status-list`

## Result

The trial passes the basic portability check:

- it uses the existing V2 kit rather than page-specific decoration;
- mobile and narrow captures report zero horizontal offenders;
- the initial product page reads as an actual landing page, not only a system board;
- the content-budget pass caught and fixed a weak mobile headline wrap.

## Remaining Risk

One trial page is promising but not enough to fully promote V2 over V1. The next decision should be whether to:

1. make `/v2/` the recommended public path while keeping V1 as archive;
2. replace the public root with a V2 landing page;
3. build one more non-fantasy-ish page from V2 to test wider applicability.
