# HoMM2 x Solarpunk V2 Slice 01 - Mobile Gateway

Date: 2026-06-01
Branch: `v2-system-reset`

## Goal

Create the first isolated V2 production slice without rewriting the existing V1 pages.

The slice proves a smaller mobile-first kit:

- compact navigation
- readable vellum surface
- brass command plate
- route/status rows
- water inspection module
- material badge/chip proof
- asset-backed framed visual slot

## Files

- `v2/index.html`
- `css/v2.css`
- `assets/v2/solar-civic-gate.svg`
- `tools/regression-smoke.js`
- `tools/visual-capture.js`

## Design Decisions

- V2 starts from mobile 390px, not desktop compression.
- The top navigation is a compact bar instead of a large menu plaque.
- The primary graphic is an SVG asset slot, not loose HTML decoration.
- The hero copy uses a dark-on-vellum reading surface to avoid light text on light backgrounds.
- RU and EN labels are included in the visible UI as a content-budget proof.
- `node tools/regression-smoke.js` now includes the V2 page and checks compact nav plus RU/EN proof labels.

## Result

The first V2 slice is directionally cleaner than V1:

- no horizontal overflow in desktop/mobile/narrow captures
- compact top navigation passes the smoke budget
- hero text uses readable dark ink on vellum
- RU/EN labels do not break into one-letter wraps
- the core visual motif is asset-backed

## Remaining Risk

This is still only one gateway slice. It should not be called a full design system until:

1. the same primitives are extracted into a reference board;
2. a second applied page uses them;
3. the asset layer is expanded beyond one SVG motif;
4. desktop composition receives the same level of design pressure as mobile.
