# V2 Slice 10 - Canopy Clinic Service Recipe

## Goal

Add one more real product recipe without sandbox vocabulary before physically splitting `css/v2.css`.

## Direction

Canopy Clinic is a compact service/booking page for yard water care: inspect water, read shade, create a repair route, and book a visit.

This tests a lighter product shape than ANT School, the launch page, the dossier, or the control board.

## Changes

- Added `v2/canopy-clinic.html`.

- Linked the page from the V2 gateway and reference recipe board.

- Updated README, starter kit, acceptance boundary, and CSS boundary notes.

## Acceptance Focus

- Production copy only: no visible proof/trial/reference vocabulary.

- First screen is intentionally shorter than the heavier ANT hero.
