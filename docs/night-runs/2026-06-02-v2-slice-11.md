# V2 Slice 11 - Physical CSS Split

## Goal

Turn the V2 CSS boundary from a documented map into an actual authoring structure without changing page-facing stylesheet URLs.

## Changes

- Kept `css/v2.css` as the compatibility entrypoint.
- Added ordered authoring layers:
  - `css/v2.tokens.css`
  - `css/v2.shell.css`
  - `css/v2.components.css`
  - `css/v2.reference.css`
  - `css/v2.recipes.css`
  - `css/v2.responsive.css`
- Preserved byte-for-byte cascade parity by splitting the previous monolith into ordered sections.
- Updated README, starter kit, acceptance notes, and CSS boundary documentation.

## Rule

New V2 styling should be added to the narrowest split file:

- tokens/base -> `v2.tokens.css`
- navigation/shell -> `v2.shell.css`
- reusable primitives -> `v2.components.css`
- reference-only proof surfaces -> `v2.reference.css`
- page-local recipes -> `v2.recipes.css`
- media queries -> `v2.responsive.css`

Keep HTML linked to `css/v2.css` until there is a concrete delivery reason to expose multiple stylesheet links.
