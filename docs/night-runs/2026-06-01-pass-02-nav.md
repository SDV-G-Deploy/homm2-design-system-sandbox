## What Changed

### Shared shell contract

- Reduced default .site-header padding, gap, sigil size, brand type size, and nav plaque density.
- Reduced default .site-shell-topbar, .site-shell-nav a, and .site-shell-breadcrumb density.
- Reworked mobile behavior in shared CSS:
  - .site-header no longer becomes a tall stacked block at tablet/mobile widths;
  - scene nav becomes a compact horizontal scroll rail;
  - site-shell nav becomes a compact horizontal scroll rail;
  - secondary brand subtitle is hidden on smaller widths;
  - breadcrumbs are hidden on the smallest screens.

### Fairy Journeys

- Removed local reinforcement that kept the shell taller than necessary.
- Reduced top margin and first-screen padding so the page reaches the hero object sooner.
- Tightened local nav pill sizing to match the shared contract.

### Reference

- Reduced intro header spacing, title size, supporting copy size, mode-chip padding, and TOC density.
- Kept the same information architecture, but made the operator surface reach #component-proof earlier.
